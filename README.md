# Jersova Jersey

Custom sports jerseys, shorts and training pants — **Wear Your Identity.**

Live site: [jersovajersey.in](https://jersovajersey.in)

## Pages

| Page | Description |
|---|---|
| `index.html` | Home — hero, featured designs, stats, process, testimonials |
| `jerseys.html` | Full catalog (157 designs) — filterable by T-Shirts / Shorts / Pants and sleeve length |
| `about.html` | Brand story, timeline, values |
| `contact.html` | Enquiry form + FAQ, with a direct WhatsApp send option |

## Stack

Plain HTML, CSS and vanilla JavaScript — no build step, no dependencies. Fonts loaded from Google Fonts (Roboto).

## Structure

```
index.html, jerseys.html, about.html, contact.html   Pages
css/style.css                                         Shared styles
js/common.js                                          Shared behavior (nav, cursor, reveal animations, ripple)
images/                                                Optimized web assets used by the site
assets/                                                Original source design files
```

## Running locally

No build step required — serve the folder with any static file server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
